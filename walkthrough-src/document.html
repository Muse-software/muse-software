How to read this

Ten routes, each shown the same way: the first desktop screen, the last desktop screen, and the full mobile page, in both English and Arabic. Key copy is quoted next to each screenshot so the words stay readable at print scale.

RouteWhat it is for
/The landing: thesis, what we do, who for, why now, objections, one ask
/exploreThe full version of the three approach cards, so a buyer can pick one door or combine
/services/*Three deep pages, one per service. Same arc each time: hero, why, what we do, FAQ
/aboutWho we are and why now, without inflation or fake proof
/careersRoles plus a human fallback for candidates
/contactThe fastest path to a human. No sales layer
/get-startedStructured intake for a scoped project
/newsletterSubscribe to the field notes
/privacy, /termsLegal boilerplate, 5 to 6 sections each. Summarised on the last page
Screenshot legend
  • Desktop top: first screen at 1440px, the hero and what opens the page.
  • Desktop bottom: the last screen at 1440px, final CTA and footer.
  • Mobile top: the first screen at 390px. The full mobile page runs tens of screens tall, so the hero screen stands in for it; the quoted copy covers the rest.
Two languages, one site

Both locales carry the same keys and the same structure; nothing is missing in one and present in the other. The English and Arabic are written independently, so sentences, lengths and register differ on purpose. 404 and the legal pages are single-page boilerplate and are covered on the last page.
