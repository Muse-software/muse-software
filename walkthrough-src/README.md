# Muse Site Walkthrough source

Builds `Muse-Site-Walkthrough.pdf` (repo root): every page of muse.sa in
English and Arabic, desktop and mobile screenshots, key copy quoted
verbatim from the site content.

## Rebuild

```sh
# 1. serve the site (needs node 24; the build must be fresh)
npm run build && npm run start -- -p 3100

# 2. take the screenshots (playwright lives in ~/Downloads/personal/pdfenv)
export PATH="$HOME/Downloads/personal/pdfenv/bin:$PATH"
python3 shoot.py          # writes assets/screens/<locale>/<route>*.png

# 3. render the PDF
python3 build.py          # writes ../Muse-Site-Walkthrough.pdf
python3 measure.py        # page fill + silent-overflow check
```

## Files

| File | What it does |
|---|---|
| `document.html` | The 17 pages. All copy lives here, quoted from the site |
| `house.css` | Muse house style plus the screenshot components (.shot, .locrow, .ctable) |
| `shoot.py` | Captures desktop top/bottom (1440px) and mobile hero (390px) for all 10 routes x 2 locales |
| `build.py` | Renders document.html to PDF with headless Chromium |
| `measure.py` | Reports page fill and flags silent overflow |
| `dump.mjs`, `dump-nested.mjs` | Dump the live EN/AR strings to /tmp for the author |
| `assets/` | Muse logo SVGs |
| `assets/screens/` | Screenshots. Gitignored, regenerated by shoot.py |
| `fonts/` | Space Grotesk + IBM Plex Sans Arabic (woff2) |

## Notes

- Mobile full-page screenshots run ~13,000px tall (the site's real mobile
  layout), so the walkthrough shows the mobile hero screen instead; the
  quoted copy carries the rest.
- The PDF embeds the screenshots, so it lands at ~7.5MB.
- Punctuation and font checks are part of the verification: no em/en dashes,
  no curly quotes, Space Grotesk + IBM Plex Sans Arabic only.
