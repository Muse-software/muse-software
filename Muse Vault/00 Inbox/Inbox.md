# Inbox

Dump zone. New notes land in this folder by default, so nothing gets lost while you are moving fast.

Rules that keep it from becoming a graveyard:

1. Capture without thinking. One idea per note, bad titles are fine.
2. File during the [[Weekly Review]]. Every note either moves to a real folder, gets merged into an existing note, or gets deleted.
3. If a note has sat here for three weeks untouched, delete it. It was not important.

## Quick capture targets

- A product idea worth building goes to `02 Ventures` using [[Venture]]
- A content idea or a post worth making goes to `03 Marketing`, see [[Content Engine]]
- A product worth studying goes to `06 Research` using [[Teardown]]
- A client lead or conversation goes to `04 Studio/Clients` using [[Client]]
- A choice you made and want to remember goes to [[Decision Log]]
- A person worth remembering goes to `08 People` using [[Person]]
