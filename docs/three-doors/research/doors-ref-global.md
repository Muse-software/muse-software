## Cross-site findings

### Eyebrow usage — the answer
- **None of the six sites uses a per-card eyebrow.** Every site that uses eyebrows at all uses exactly **one per section** (Tenex "Our approach"; Netlify "How it works / Get going / Workflow / Platform / Scale / Use cases"; Vercel "Agent Stack / Core Platform / Tools" as dropdown column labels).
- **Linear and Basecamp use no eyebrows at all** — pure title + one-liner.
- 37signals' only eyebrow-like device is the "Signal NN." number prefix.
- Verdict for Muse: one small eyebrow per door section (or none), never a label above each card. Abdullah's "eyebrow-heavy" rejection is validated by every reference site.

### Balanced card anatomy that actually ships
- **Tenex / Linear / Netlify / Vercel share the same skeleton:** 1-4 word title → one-liner of 6-14 words → one CTA. Description word counts stay within ~2x of each other across the trio (Linear: 12-14 words per door; Netlify: 10-14; Tenex: 16-23).
- **Titles as verbs, not nouns:** "Start building with an AI agent", "Define the product direction", "Move work forward", "Make product operations self-driving", "Build fullstack apps", "Go live everywhere" — the doors read as actions, which is exactly how to separate Build / Ventures / Think as three *ways to work* rather than three *departments*.
- **One-liner formulas to steal:** "From X to Y" (Linear, Netlify), "X not Y" (Tenex), "One platform to X and Y" (Netlify), "No X. No Y." (Tenex), "Every X gets a Y" (Netlify), "Start with X" (Netlify).
- **Proof lives in the one-liner, not a separate row:** Vercel's cards pair a capability title with a customer-stat line ("Notion powers millions…"); Tenex's Engineering card ends in "you pay for features delivered, not hours logged."

### CTA mechanics
- **Identical CTA on every card** (Tenex: "Learn more" ×3 + global "Get started") = doors feel like one system.
- **Distinct verb CTA per card** (Netlify: "Build now", "Import a project", "Get started with CLI", "Try Netlify Drop", "Explore AI Gateway") = each door is its own offer.
- **No text CTA at all** (Linear: circular arrow; Vercel: whole card is a link) = cleanest look, works when the whole card is clickable.
- Educate + convert pairs: "Learn more" + "Get started" (Tenex), "Start building" + "Talk to sales" (Netlify), "Deploy now" + "Talk to sales" (Vercel).

### Differentiating "for clients" vs "own products" vs "knowledge"
- **37signals** is the cleanest model for the Think door: products as nav links, knowledge as a numbered list of punchy opinion titles, zero descriptions needed.
- **Vercel's dropdown** is the model for a products door: three column eyebrows, plain product names, no copy.
- **Tenex** is the model for a client-services door: the whole page is "we do this for you", cards describe the engagement model (squads, partnership, outcome-based), CTAs go to "Get Started".
- Nobody in this bank sells all three lanes on one page — that's Muse's own structure — so the borrowing is: keep the three sections visually identical in weight (Linear's doors), give each a distinct verb title (Netlify), use one eyebrow per section or none (everyone), and let the card copy describe the *way of working*, not the feature list (Tenex).
