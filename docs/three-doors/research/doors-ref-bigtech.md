## Mechanics worth borrowing (summary)

1. **One grammar skeleton per row, zero eyebrows.** Stripe's four cards, Notion's lanes, Framer's agent cards and Shopify's trio all repeat a single pattern per section — title (2–5 words) + one-liner body (~5–15 words) — with no kicker/eyebrow labels above titles. The title carries the lane; the body is a single short sentence. Notion's "Docs — Simple and powerful." is the extreme case.
2. **Length balance is enforced by sentence count, not word count.** Stripe bodies are ~2 sentences each; Notion one-liners are 2–7 words each; Shopify's trio bodies are exactly one sentence each. Long-form Framer card 4 gets away with length because it is four equal 6–8 word imperatives.
3. **Verb-first or verb-only distinctions.** Shopify runs six cards on one verb ("Sell…") differentiated by object; Framer differentiates lanes by the verb's object ("Design / Run your CMS / Code / Connect"); Notion one-liners start with verbs ("Answers…", "Assigns…", "Summarizes…").
4. **One recurring CTA verb per set.** Stripe: "Start accepting payments" / "Start now" / "Explore Billing"; Framer: "Start with Agents" ×3; Shopify: "Start for free". One deliberate exception per system (Framer's "Connect to any agent") proves the pattern is intentional.
5. **The two-fragment payoff line.** "Less tracking. More progress." (Notion), "Manage more. Publish faster." (Framer) — two 2–3 word sentences do the work of a description and read as designed, not transcribed.
