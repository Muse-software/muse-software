# Muse documentation boundary

Muse company knowledge is no longer stored in this public website repository.

## Canonical private repository

`https://github.com/alsubaieabdullah/muse-documentation-vault`

The private repository contains strategy, ventures, research, marketing work, people context, presentations, working sources, final deliverables, verification evidence, and project history.

## This public repository contains

- Deployable website code.
- Safe public website documentation.
- Technical plans and verification evidence needed to maintain the site.

## Rules

- Do not create a new `Muse Vault` folder in this repository.
- Do not copy candidate research, team notes, unpublished ideas, or operating context into public branches.
- Historical website documents may refer to old `Muse Vault/...` paths. Resolve those references against the private repository.
- Removing the folder from the current tree does not erase it from earlier public Git history. A history rewrite is a separate decision because it changes commit identities and existing clones.
